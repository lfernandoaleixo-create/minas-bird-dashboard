# Nomenclatura de Mutações Ring Neck - Criadores Brasileiros

## Fontes:
1. ringneck.com.br (referência brasileira)
2. Galpão das Aves (calculadora genética)
3. Instagram/TikTok de criadores

## Nomes Usados pelos Criadores Brasileiros:

### Cores Base / Série Azul:
- Verde (selvagem)
- Azul
- Turquesa (ou "Azul Turquesa" ou "Turquesa Azul")
- Aqua (pouco mencionado no Brasil, mais usado internacionalmente)

### Ligadas ao Sexo:
- Lutino (verde + ino)
- Albino (azul + ino)
- Cremino (turquesa + ino)
- Canela (cinnamon)
- Pallid / Lacewing (usam ambos os termos)
- Opalino (opaline)
- Platinum (platinum)

### Dominantes:
- Fator Escuro SF / DF
- Cobalto (azul + fator escuro SF)
- Malva (azul + fator escuro DF)
- Violeta SF / DF
- Verde Cinza (verde + cinza)
- Cinza (azul + cinza)
- Arlequim Dominante SF / DF

### Recessivas:
- Cleartail (ou "Clear" no Galpão das Aves)
- Diluído (dilute)
- NSL Ino (não ligado ao sexo)
- Arlequim Recessivo
- Bronze Fallow
- Pastel

### Combinações Populares:
- Skyblue = Azul + Canela (CONFIRMADO por ringneck.com.br)
- Silver = Azul + Cinza + Canela (CONFIRMADO por ringneck.com.br)
- Jade = Verde + Turquesa + Canela (?) — aparece no Galpão das Aves
- Cobalto = Azul + Fator Escuro SF
- Malva = Azul + Fator Escuro DF
- Verde Escuro = Verde + Fator Escuro SF
- Oliva = Verde + Fator Escuro DF

### Notação de Splits:
- Usa "/" para separar splits
- Exemplo: "VERDE/AZUL/CANELA" = Verde portador de Azul e Canela
- "VERDE CINZA/AZUL" = Verde Cinza portador de Azul

### Observações Importantes:
1. "Turquesa" é o nome mais usado (não "Parblue")
2. "Arlequim" é o nome para "Pied" (tanto dominante quanto recessivo)
3. "Canela" é o nome para "Cinnamon"
4. "Opalino" é o nome para "Opaline"
5. "Diluído" é o nome para "Dilute"
6. "Fator Escuro" é o nome para "Dark Factor"
7. "Cremino" = Turquesa + Ino (CONFIRMADO)
8. "Skyblue" = Azul + Canela (nome próprio usado no Brasil)
9. "Silver" = Cinza + Canela (ou Azul + Cinza + Canela)
10. "Clear" parece ser usado no lugar de "Cleartail" no Galpão das Aves
11. "Jade" aparece como mutação — precisa confirmar se é Verde + algo

### Nomes que PRECISAM ser corrigidos no nosso sistema:
- "Verde (Selvagem)" → manter como "Verde" apenas quando visual
- "Ino (Lutino/Albino)" → manter como "Ino" para o gene, mas mostrar "Lutino" ou "Albino" no fenótipo
- "Pallid (Lacewing)" → "Lacewing" é o nome mais usado no Brasil para Pallid
- "Clearhead Fallow" → manter em inglês (não tem tradução popular)
- "Dun Fallow" → manter em inglês
- "Bronze Fallow" → manter em inglês
- Adicionar "Skyblue" como nome composto (Azul + Canela)
- Adicionar "Silver" como nome composto (Cinza + Canela ou Azul + Cinza + Canela)
- Adicionar "Jade" se confirmado
